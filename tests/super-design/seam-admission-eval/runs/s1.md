## Notes

- **Graph shape.** The longest chain has 2 rounds. `.1` gates `.2` and `.3`, which then run in parallel. `.1` lands only the artifact they consume, `default_dest`, plus `where`, which is a direct CLI exposure of that artifact. `where` is too small to be its own bead.
- **No new seam admitted.** `config.default_dest` is owned by a single bead (`.1`, `owns:`) and consumed by the others, so neither parallel task chooses its own form. Controlling the home directory for R2's check needs no seam: setting `HOME` makes `os.path.expanduser` deterministic.
- **Configuration smoke (dir, zip).** Each leaf already runs its own command once per enumerated backend, so the smoke exercise lives inside the leaves and needs no separate row.
- **Shared files.** Only 2 parallel leaves (`.2` and `.3`) share `commands.py` and `__main__.py`, so no `Split file:` row is needed. The merge gate absorbs the append-only subparser additions.
