## Spec text to add (root spec, under R1's design)

```markdown
### snapshots.csv layout

Owned by exp.1 (`stash export`); consumed by exp.2 (`stash report`).

- Encoding UTF-8, RFC 4180 CSV: comma-separated, fields containing a comma, double quote or
  newline are double-quoted with embedded quotes doubled; line ending `\n`.
- First line is a header, exactly: `name,backend,size`.
- One row per snapshot, every snapshot included (R1: "all snapshots"); row order is unspecified.
- `name`: the snapshot name as stored, verbatim.
- `backend`: the backend identifier as stored, verbatim; totals group on exact string match.
- `size`: snapshot size in bytes, a non-negative base-10 integer with no unit or separator.
- With zero snapshots the file holds only the header line.
- The reader locates columns by header name, not position, and fails with an error naming the
  missing column if any of the three is absent; extra columns are ignored.
```
