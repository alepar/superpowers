Notes:
- Only one seam is admitted. The `dir`/`zip` branching inside `snapshot_entries` follows the existing per-backend `if` style in `commands.py`, `config.py` and `report.py`. No backend-reader abstraction is admitted: no existing call site this change touches is restructured, so class N does not apply.
- `.2` and `.3` both append to `stash/commands.py`, `stash/__main__.py` and `stash/report.py`, but each adds its own separate functions and subparser. With two leaves the overlap is under the split threshold of three, so the serial merge gate handles it and no `Split file:` row is needed.
- No operational follow-on. Signing and remote storage are out of scope according to the spec.
