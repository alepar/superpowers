## Seam admission

None admitted. The only candidate was a class-V clock seam for R2's determinism requirement. The direct check
works: a pure formatter that takes `now` as an argument can be tested deterministically with no new
interface, type or injectable clock. There is a single leaf, so no parallel boundary (P) exists. Age
formatting does not branch on backend, so there is no variation now (N).

## Notes

- The whole change is one small, cohesive edit in one subsystem. Splitting the formatter from the
  `list` wiring would leave each part below the per-bead ceremony floor and would create a seam
  between two tasks over one function. So the tree has one leaf and no edges.
- No configuration-smoke leaf. The spec lists no runtime configurations. The two existing backends
  are covered by an acceptance item on the leaf.
