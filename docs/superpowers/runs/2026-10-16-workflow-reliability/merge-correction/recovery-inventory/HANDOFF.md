## Reproduction and limits

Read `limitations.json`. The population is deliberately bounded to canonical outputs then known output references; recursively archived cloned source/test fixtures and dispatch inputs are omitted with metadata accounting, not cleared. Source classification is based on complete returned objects and explicit headings/context. Prose requirements still need owner applicability judgments; the raw reports remain available for that review.

To reproduce the read-only capture into this temporary directory: `python3 inventory.py`, then `python3 reduce.py`, `python3 references.py`, `python3 finalize.py`. The first step recaptures local untracked snapshots at its execution time; those hashes may change while other workers are active. Pinned committed sources remain reproducible using `git show <baseline>:<path>`. Subsequent reductions consume frozen raw snapshots, and the artifact SHA manifest records this delivered snapshot. No helper under test is executed by these scripts.
